Lector de Fichas

Pegá la ficha como la tengas: el texto copiado del foro, el código del post (BBCode y HTML) o la página del tema guardada (.htm). Sale en JSON o como código corto para cargar en otras herramientas. También podés pegar un código AVK1. para volver a ver la ficha.

    Cómo usarlo en otras herramientas
    
    
      
      
    1. Pegá la ficha a la izquierda o subí la página del tema guardada desde el navegador (Ctrl+S). Si el tema tiene respuestas de otros usuarios o el registro de canjes, se ignoran. Revisá los avisos (niveles mal sumados, listas incompletas).
      2. 
      
    2. JSON es legible y sirve para revisar. Código es la misma ficha comprimida (empieza con AVK1.): es lo que se pega en el tracker o en la calculadora.
      3. 
      
    3. “Descripciones” agrega los textos largos (historia, descripciones, trasfondos, talentos, objetos). Sin ellas el código queda mucho más corto.
